# tunenote

Tune CSV/TSV note tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tunenote/

## Install / run

```bash
git clone https://github.com/theworker02/tunenote.git
cd tunenote
node src/cli.js
node --test
```
